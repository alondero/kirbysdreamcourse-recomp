What is realistic here?

The ability badge has exactly the same position, size and symbol in both detail states. Only the surrounding information changes. Shot placement is a schematic native-field sample, identical across these layouts; implementation would retain the game's live shot coordinates, not force a new screen-center or ball-following rule.

No new ability names, percentages, timers, predictions, alerts or current-hole score counters are added to the in-game preview.
